# 勢包技能共用與 V2 遷移

2026-09-22 原始碼檢查點。範圍是 `heg_momentum` 九名武將；`heg_momentum_equip` 太平要術不在此批武將技能重寫範圍。保留工作區其他既有修改。

## 共用技能

| 武將／來源 | 使用的既有技能 ID |
| --- | --- |
| 李典 | `xunxun`、`wangxi` |
| 馬岱 | `mashu`、`qianxi` |
| 孫策 | `jiang` |
| 暴凌取得 | `benghuai` |
| 魂殤暫時取得 | `yingzi`、`yinghun` |

六個直接／取得技能 ID 改用現有定義，魂殤另沿用兩個共用 ID。刪除勢包內相應重複類別及過時技能翻譯，相關 helper 由既有註冊表提供。共用定義即使仍是 V1，也不在本批另寫 V2 複本；國戰及身份模式均採共用定義的現版規則。

## 獨立技能

| 技能 | V2 形式 | 模式及生命週期 |
| --- | --- | --- |
| 横江 | Trigger + MaxCards | 按來源實例記錄本回合對象、減少上限數及棄牌狀態；related V2 helper 結算回合末摸牌。 |
| 闺秀 | Trigger + ViewAs | 國戰明置摸二、移除武將回復一；身份模式保留準備／出牌階段限定摸二及失去技能後回復。限定狀態按實例保存。 |
| 存嗣 | ViewAs | 國戰移除來源武將；身份模式失去闺秀及本次存嗣實例；再授予目標勇決，非自己摸二。限定狀態在 pay 扣除，來源移除在 V2 明置後、逐目標效果前執行。 |
| 勇决 | Trigger | 國戰限定友方、真實單張殺並由用殺者決定；身份模式保留由持有者決定收回首張殺。首牌材料按來源實例記錄，取得前重查牌位；身份模式同時更新原移牌資料。 |
| 鹰扬 | Trigger | cost 保存加／減三的選擇；effect 修改原拼點資料，點數限制在 1–13。 |
| 魂殇 | Trigger | 體力一的準備階段授予共用英姿／英魂；related helper 保存真正新建的實例 ID，回合末、死亡或來源移除時只撤回這些授予。 |
| 断绁 | ViewAs | 沿共用 ActiveSkillCard，依既有連環禁制選目標並呼叫 setPlayerChained。 |
| 奋命 | Trigger | cost 建立目標列表，逐目標 V2 攔截後棄牌。 |
| 横征 | Trigger | 國戰體力一／空手；身份模式保留體力不大於一／空手。逐目標取得牌後中斷普通摸牌，記錄暴凌條件。 |
| 暴凌 | Trigger | 國戰主將移除副將；身份模式保留发动過横征的覺醒條件。增加上限、回復三並取得共用崩壞；覺醒狀態按實例記錄。 |
| 穿心 | Trigger | 國戰保留出牌階段、不同勢力及副將限制；身份模式保留失去一項技能／棄裝失血的選擇。目標攔截後回傳中斷原傷害。 |
| 锋矢 | Trigger + ViewAs | 國戰使用既有圍攻判定及陣法召喚；身份模式保留双方相鄰時可令目標棄裝的效果。 |
| 悟心 | Trigger | 以既有勢力人數 API 取得觀星數；沿普通觀星入口處理。 |
| 弘法 | Trigger + ViewAs | 天兵補充、失血防止與人數修正在 V2 cost/pay/effect 分離處理。附加殺使用跨玩家 parentRef 綁定確切弘法來源；移除來源由既有附加技能機制清理。 |
| 问道 | ViewAs | 共用 proxy 支付紅牌後尋找場上／棄牌堆太平要術。 |

保留 `HCunsiCard`、`HDuanxieCard`、`HWendaoCard` 字串作使用次數記錄鍵，刪除其 C++ 卡類與註冊。弘法選天兵改成 AG 選牌；增加人數改成數字選項，選擇放在 SkillContext，不再合成 HHongfaCard／HHongfaTianbingCard 或經 Player Tag 傳遞。

## 陣法與退役來源

| 項目 | 本批結論 |
| --- | --- |
| 陣法是否已實現 | 原工作區已有 `summonFriends`、`inSiegeRelation` 與隊列判定；鋒矢已有舊版效果。 |
| 鋒矢本次接線 | 主動召喚使用 ViewAsSkillV2，條件引用 `canSummonOriginalHegemonyArray`；付款／明置後呼叫既有 `summonFriends("Siege")`。觸發效果改為 TriggerSkillV2。 |
| 其他陣法 | 不以本次鋒矢修改推定其他包已完成遷移或驗收。 |
| 闺秀來源已移除 | 派送器增加預設關閉的 `acceptsRemovalEvent`。只接受事件角色本人、名稱相符且經 GeneralRemoved 定義／EventLoseSkill 實例資料核實的來源；回調使用事件 context，不建立或復活實例。 |
| 同名存續來源 | 移除事件使用零實例的事件來源，不展開主將／副將／後天同名存續實例。普通 V2 仍須有效實例；未選擇加入的技能不受影響。 |

## 翻譯與 AI

| 項目 | 處理 |
| --- | --- |
| 技能說明 | 十五個独立技能皆具 `:heg_技能_p` 身份說明；原身份版本取自遷移前勢包，無舊身份版的新增技能使用明示的身份規則。`HMomentumPackage.lua` 同步横江回合末結算、魂殤／断绁條件、鹰扬上下限及弘法附加技能／天兵提示，清除退役提示。中文保持簡體，武將名保持 `[国]` 後綴。 |
| AI | 存嗣、断绁、问道、闺秀及鋒矢使用 `ai_fill_skill` 和 ActiveSkillCard；弘法殺保留技能 ID `heg_hongfa_slash`，移除旧专属卡请求。共用技能不覆蓋其既有 AI callback。 |
| 外部來源 | 只回寫 `ai/original-hegemony/heg-momentum-ai.lua` 到 extensions 權威倉庫，核對 SHA-256；不修改該倉庫其他 dirty 檔。 |
