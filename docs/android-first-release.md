# Android 首版功能與驗收

工作樹：`L:/finaldebug/QSanguosha-v2`，`debug@9b7920c4469d42f40f8e4bcb66d15d8bcb6e727a`。
本文件記錄 CP2–CP4 的功能契約；CP1 的 APK 建置證據不代表下列功能已通過裝置驗收。

## 使用流程

| 階段 | 行為 |
|---|---|
| 第一次開啟 | 先進入資源管理。完整聲畫包尚未驗證成功時，不建立遊戲 Engine 或開局。 |
| 匯入聲畫 | 以 Android 系統檔案選擇器選取配套 ZIP，前景串流解壓至私有暫存版本。 |
| 完整性 | ZIP 路徑、大小、CRC、manifest SHA-256 與 APK 的預期媒體清單均須符合要求。 |
| 中途離開 | 切背景、鎖屏或按取消會取消本次匯入；現用版本保留。下次重新選取 ZIP。 |
| 套用 | 匯入、整包啟停、替換、移除與順序調整於重新啟動生效。 |
| 啟動失敗 | 啟動標記未清除時先進入回復介面；可以停用上次匯入或切回上一版本。 |
| 遊戲中管理 | 牌桌浮動選單提供資源管理；不在已建立的 Engine 中熱載入 Lua。 |

## 擴展

隨 APK 附帶核心、現行擴展、AI、翻譯與基本介面。沿用 `TODO/human` 的缺檔釋出方式，
保留已有腳本修改；完整媒體另外部署。匯入使用可信 Lua 模式，保留 `io`、`os`、`package`
等既有能力。ZIP 安全檢查限制的是匯入寫入位置，不是 Lua 執行權限。

| 格式 | 契約 |
|---|---|
| 單一 `.lua` | 放入 `extensions/`，整包名稱也是新腳本名稱。 |
| 擴展 ZIP | 保留 `extensions/`、對應 Lua／AI、翻譯及媒體的既有相對目錄。 |
| 宣告 | 可附 `runtime-content.json`，使用 schema 2／`declared-v2`；有效宣告在 Engine 載入前完成。 |
| 替換 | 相同整包名稱替換原包，保留其載入位置；跨包檔案衝突顯示錯誤。 |
| 原版 | 隨包原版保留供還原；管理操作不能修改 APK 或隨包 `config.lua`。 |
| 順序 | 隨包既有順序保留，新項目預設按名稱排序；調整後可匯出有效宣告。 |
| 身份 | 有效規則順序、依賴與 Lua 參與校驗；AI、翻譯與媒體維持原有角色界線。 |

原生、Web／WASM 與伺服器須使用同版建置及相同規則內容。Protocol V2 不變，內容身份
使用 `declared-v2`。Web／WASM 安裝器會實際寫入有效宣告，不能只傳遞 manifest metadata。

## 產生配套聲畫包

```powershell
python tools/android/create-media-package.py . builds/android-release/qsan-media.zip
```

工具只收集 `image/`、`audio/`、`font/`，排除符號連結、備份與執行期雜檔，產生 ZIP64
與 `qsan-media.json`。封裝期間逐檔再次核對大小與 SHA-256，來源改變時不發布輸出。
APK 建置另產生獨立的媒體清單；只有自行宣告少量檔案的 ZIP 不能解鎖開局。

## 生命週期與操作

| 情境 | 首版契約 |
|---|---|
| 觸控 | 點按選取、長按預覽；首裝牌桌控制預設 1.25 倍，技能／確認觸控範圍至少 48 邏輯像素；次要功能使用浮動選單，牌桌與鍵盤避開系統保留區。 |
| 單機背景 | 同程序 Room 暫停進度和待回覆時間；返回前景不解除玩家手動暫停。 |
| 初始化背景 | 允許 Lua worker 安全完成初始化，延後開局及自動 ready。 |
| 連線背景 | 伺服器繼續計時；返回前景同步或重連，過期互動不送出。 |
| 程序回收 | 離線局不恢復；下次開啟提示中斷，返回首頁。 |
| 音畫 | 背景停止輸出並保存可恢復的播放狀態；GL context 重建後重新建立 Spine GPU 資源。 |

Android 13 隔離模擬器實際操作發現並修復了資源頁系統列裁切、拖曳誤點，以及預設
ZIP 暫存位置不可寫入。匯入現在使用 app 私有 staging 目錄，啟動時清除已知命名的
殘留 spool；更新安裝保留內容，切背景取消匯入後現用版本不變且暫存已清理。
此模擬器為 x86_64 執行 arm64 翻譯、4 KB 頁面；不能代替 arm64 實機或 16 KB 執行驗收。
完整 ZIP 已經系統檔案選擇器匯入，重新啟動後 `active_media_ready=true`、保留上一版本，
首頁建立完成並清除啟動標記。首次驗證大量檔案的空白等待已改為 worker 配合載入畫面，
背景時允許檢查安全完成、回前景才銜接 Engine。
連線實測另發現 Android 沒有桌面 `USER` 環境值，且原讀取鍵與連線介面寫入的
`UserName` 不同；現在沿用儲存名稱並為空白名稱提供預設值。
完整對局與 CTest 批次最終結果以本輪驗證總表分別記錄。

後續已補齊 APK 支援 Lua 的有效宣告，正常 Qt build10 建置與靜態稽核通過。
