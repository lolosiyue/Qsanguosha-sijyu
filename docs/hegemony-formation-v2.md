## 同一 V2 技能的身份局分流

沿用現有 `Config.EnableHegemony` 模式開關；技能 ID 不變，身份局正文使用 `:heg_*_p` 翻譯鍵。國戰分支保留原隊列、圍攻與同勢力限制。

| 技能 | 身份局行為 |
| --- | --- |
| 天覆 | 自己或鄰座回合開始，由回合角色決定是否授予技能擁有者既有 `kanpo`；於該回合結束回收。 |
| 鶴翼 | 自己回合結束，選包含自己的至少兩名連續存活角色，可跨首尾座位或選全場；其餘角色獲得既有 `feiying`，於自己的下次回合結束先回收，再提供新一次選擇。 |
| 資糧 | 可將田交给任一受傷存活角色，不限制同勢力。 |
| 守成 | 任一角色於其回合外失去最後的手牌後，擁有者可發動，再由該角色選擇是否摸一張牌；身份局不限制同勢力。生息維持原有共用行為及正文，不另設 `_p` 翻譯。 |
| 尚義 | 展示手牌後選觀看手牌並可棄黑牌，或私下觀看身份；自己空手仍可發動，身份通知與日誌只送給觀看者。 |
| 鳥翔 | `TargetConfirmed` 時，擁有者與殺使用者皆鄰接目標即可選擇兩閃；不限制至少四人，國戰仍為強制圍攻效果。 |
| 疑城 | 擁有者可令任一殺目標摸一棄一。 |
| 千幻 | 任一受傷存活角色自行決定替擁有者收幻，同花色棄掉新幻；擁有者可移除幻取消任一基本／錦囊牌的唯一目標。 |

天覆／鶴翼的存續資料綁定技能實例，投影為帶有 `parentRef` 的附屬授技；回收保留其他來源的原生或獲得技能。身份局關閉三項陣法召喚入口。資糧、疑城與千幻從 `ctx.invoker` 取得事件角色，避免把 V2 cost 的擁有者參數誤當成受益者。

外部 formation AI 在身份局註冊對應回應，國戰仍經 bundle gate 載入；不載入整套國戰共用策略。`tests/hegemony-formation-test.cpp`（`--suite hegemony-formation`）涵蓋鶴翼連續／跨首尾／全場與非法選擇、空手尚義、鳥翔頻率及召喚模式門檻；本批僅靜態檢查，未執行案例。
