# Google Sheets 對局前端

Apps Script 將玩家可見狀態與操作候選呈現在工作表，Windows gateway 連接原生 Sheets bridge。

## 開始使用

1. 依[主機準備](../docs/google-sheets-setup.md#主機準備)建置 bridge 並啟動 gateway。
2. 依[Sheets 安裝](../docs/google-sheets-setup.md#sheets-安裝)加入 Apps Script，配對自己的文件。
3. 在工作表選牌與目標，透過側欄更新、預檢及提交操作。
