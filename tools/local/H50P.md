# H50P fallback SmartAI probes

`h50p_relationship_probe.lua` extracts the actual relationship methods (including
controller wrappers) from a supplied `smart-ai.lua`. It uses 50 fake players and
counts `objectName()` calls at the native boundary. It does not load packages or
simulate their native costs; its CPU timings are microbenchmark results, not turn
times. It checks dense-list replacement, sorting, removal, insertion, repeated
same-length mutation, equal-name wrappers, and changing/cyclic controllers.

From the runtime checkout:

```sh
git -C /workspace/extensions-src show 9fbaf64:ai/smart-ai.lua > /tmp/h50p-before.lua
lua tools/local/h50p_relationship_probe.lua /tmp/h50p-before.lua 100
lua tools/local/h50p_relationship_probe.lua /workspace/extensions-src/ai/smart-ai.lua 100
```

The optimized membership lookup validates positive positions against the live
list. Misses still scan: this avoids stale negative results when package AI edits
lists without going through `updatePlayers`. Controller relations remain live.
Positive hits are O(1); misses remain O(n), with the query name fetched once.

The first H50P comparison used the complete existing runtime package set, seed
26092891, `QSAN_LUA_PROFILE=1 QSAN_LUA_PROFILE_SEC=5 QSAN_AI_PROBE=1`, and:

```sh
QSAN_HEADLESS_PER_GAME_TIMEOUT=900 python3 -u tools/autotest/headless_runner.py \
  --exe /workspace/Qsanguosha-sijyu/debug/QSanguosha \
  --exe-root /workspace/Qsanguosha-sijyu \
  --log-dir /workspace/auto-games/runs/CHOOSE-A-NEW-DIRECTORY \
  --modes 50p --games 1 --parallel 1 --seed 26092891 --label h50p-profile
```

Set the three profiling environment variables above for that command. The runner
adds a 120-second startup allowance to its per-game timeout. Never reuse another
runner's directory. Copy source `ai/smart-ai.lua` to runtime `lua/ai/smart-ai.lua`
before launching; the runtime copy is ignored and must not be force-added.

```sh
python3 tools/local/h50p_profile_summary.py /workspace/auto-games/runs/h50p-20260928-codex-prof
python3 tools/local/h50p_profile_summary.py /workspace/auto-games/runs/h50p-20260928-codex-after
```

Summaries report timestamps, complete turn gaps, native decision probes, and Lua
sample totals. Only each sampling interval's top ten locations were logged, so
location totals are lower bounds. Instruction sample share is not wall time.
The original runtime's `SmartAI=50 fallback=0` startup message counts LuaAI versus
base C++ AI instances; it does not mean WorldView handled all decisions.
